# lib/libc ports proved IR-equivalent AND exporting the same symbols as
# their C original, on a FreeBSD host.
#
# The sibling floor counts semantic equivalence only, and normalize_ir()
# demangles names to get it. That is right for "does this compute the same
# thing" and wrong for "can this ship": libc cannot export __adddi3 under a
# C++ name and still be libc.
#
# So this is the number that decides whether a libc port is committable,
# and like lib/msun's it is a separate ratchet rather than a redefinition.
#
# 110 = 109 ABI-equal + 1 committed, from oracle run 33 (commit
# 72f7c4928, FreeBSD 15.1, clang 21, --ir-limit 1500).
#
# It got there in one step worth recording. At the widened limit the gap
# between IR-equal and ABI-equal was 38 ports, and 25 of them were one
# directory: lib/libc/quad. quad.h declared seven of its twenty-five
# functions, outside any linkage guard, and the other eighteen were
# declared nowhere - so under C++ they got C++ linkage and libc would have
# shipped __adddi3 as _Z8__adddi3ll. One __BEGIN_DECLS and eighteen
# prototypes moved ABI-equal from 85 to 110 (commit 5a0a1136f).
#
# The thirteen still in the gap are each their own header: arm/gen/fabs.c,
# gen/dirfd.c, gen/dup3.c, nameser/ns_netint.c, powerpc64's strcpy and
# strncpy, rpc/des_soft.c, rpc/rpcsec_gss_stub.c, stdlib's hdestroy_r,
# insque and remque, string/memset_explicit.c, sys/pipe.c.
# THE SUM GAINED A THIRD TERM (run 36)
#
# Run 34, the last green one, reported 122 verified + 1 committed = 123.
# Run 36 reported 96 verified + 26 committed = 122 and failed the floor by
# one. Twenty-five ports landed in between and verified fell by twenty-six,
# so exactly one file left the candidate set without becoming a port:
# hbsd/src/lib/libc/amd64/string/strnlen.c, which run 34 named in its
# committable list - IR-equal AND ABI-equal - and which commit 4f926059c
# deleted along with ten other arch-string sources that shadowed their
# machine-independent originals through .PATH and called assembly that was
# already gone. The ABI figures moved by the same one, for the same file.
#
# So a source has three ways out of the candidate set, not two: it can be
# ported (counted by `+ committed'), it can regress (which is what this
# floor is for), or it can be DELETED - neither a .c that verifies nor a
# .cpp that shipped. The third was not accounted for, and the honest fix is
# to complete the invariant rather than to move the number: this floor is
# unchanged, and docs/migration/freebsd_oracle_removed.txt names the
# deletion with the commit that made it. tools/check_oracle_removed.py
# holds every entry to what git says, so the term cannot become a way to
# hold a floor up over a file that is back.

110
