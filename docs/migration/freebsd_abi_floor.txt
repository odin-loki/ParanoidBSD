# Ports proved IR-equivalent AND exporting the same symbols as their C
# original, on a FreeBSD host.
#
# The older floor next to this one counts semantic equivalence only, and
# normalize_ir() demangles names to get it: @_Z9usage_msgv compares equal to
# @usage_msg. That is right for "does this compute the same thing" and wrong
# for "can this ship". A function declared in a header keeps C linkage
# through __BEGIN_DECLS; one that is external but declared nowhere is
# mangled, and libm cannot ship a symbol under a new name.
#
# So this is the number that decides whether a port is committable, and it is
# a separate ratchet rather than a redefinition of the old one, because the
# old one still measures something worth not regressing.
#
# Run 12 (commit 96c555238, FreeBSD 15.1, clang 19.1.7, scope lib/msun):
# 74 ABI-equal against 88 IR-equal. The 14 in the gap are real: msun's
# __kernel_cosl, __kernel_sinl and __kernel_tanl in both ld80 and ld128
# compute the right answer and export _Z13__kernel_coslee instead of
# __kernel_cosl. lib/msun/src/math_private.h declares them with no
# __BEGIN_DECLS, so under C++ they get C++ linkage. Those ports are correct
# and unshippable, which is exactly the distinction this floor exists to
# make.
74
