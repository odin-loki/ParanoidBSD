# Manual queue (functions still failing after the automated rounds)

Generated by `docs/plan/tools/verify/repair/export_manual.sh` from `final/state.tsv` (`state.sh`). Packets live in `C:\ParanoidBSD\mined-data\manual\packets\` (`/mnt/c/ParanoidBSD/mined-data/manual/packets/` in WSL), not in git (large). Tracked here: `index.tsv` (packet, records, functions) and `functions.tsv.gz` (key, i, name, kind, status, packet) for every queued function.

Packet = a jsonl file, one line per source record (`key`, `file`, `start`, `end`, `source` = lines start-end of the file, `functions[]`: `i`, `name`, `kind`, `status`, `prose`, `contract`, `reasons`). `reasons` lists every recorded failure by round (original rejection: mechanical / Frama-C / random-testing counterexample / reviewer; round 1 and round 2 status and reason).

Status of a queued function: `still-rejected` (a mechanical check still fails), `fixed-disagree` (the DeepSeek reviewer still disagrees), `dropped` (the repair model said it is not a function: check, and fix if it is one), `fixed-unreviewed` (passes the checks, review call failed or ran out of budget), `rejected-unrepaired` (non driver-glue: repair call failed).
Packets `L*` (`packets-lowprio`, only with `LOW=1`) hold the never-attempted driver-glue functions.

Result file for a packet, jsonl, one line per function: `{"key","i","name","action":"fix"|"drop","prose","contract","note"}` (`key` and `i` exactly as in the packet; `contract` only for functions whose parameters and result are integers, booleans or enums: one line `/*@ requires <C expr>; ensures <C expr>; */`, `result` for the return value, no `\result`, parenthesise bit operations; otherwise `""`). A contract must not be weaker than the prose (that counts as a defect).
Ingest: `bash docs/plan/tools/verify/repair/ingest_manual.sh <result.jsonl> [review-budget-usd] [parallel]` (runs steps 1-3 + Frama-C and the DeepSeek review on just those functions as the next round, merges into the status table). Then `export_manual.sh` and `tag_final.sh` again.
