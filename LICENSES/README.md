# Licence texts

Reference copies of the licence texts referred to by
[`../LICENSING.md`](../LICENSING.md). They are here for convenience; the
authoritative grant for any given file is the `SPDX-License-Identifier` and
copyright header in that file.

| File | Used by |
|---|---|
| [`../LICENSE`](../LICENSE) | `AGPL-3.0-or-later` — PBSD's default licence |
| `BSD-2-Clause.txt` | 557 ported files under `pbsd/` derived from HardenedBSD / FreeBSD |
| `BSD-3-Clause.txt` | 546 ported files under `pbsd/` derived from HardenedBSD / FreeBSD |

Texts not duplicated here, because the upstream tree that needs them ships its
own copy:

| Licence | Where its text lives |
|---|---|
| The full HardenedBSD / FreeBSD licence trail | `hbsd/src/COPYRIGHT` and the per-file headers under `hbsd/` |
| `GPL-2.0-or-later`, `LGPL-2.1-or-later` and the rest of the KDE trail | the `LICENSES/` directory inside each subproject under `kde/` (e.g. `kde/kwin/LICENSES/`) |
| `CDDL-1.0` | `hbsd/src/sys/contrib/openzfs/` — see `LICENSING.md` §4.3.2 |
| `ISC`, `MIT`, `0BSD`, `BSD-1-Clause`, `BSD-4-Clause` | reproduced in full in the header of each file that carries them |
